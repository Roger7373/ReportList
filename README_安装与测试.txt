Defect List V1.2.2 · TEST
========================
本版更新：Photo Report PDF 的信息区优先，照片缩小至适合打印大小。

A4 Portrait:
1. BEFORE 1 张 + AFTER 1 张：左右并排，保持图片原比例、不裁切。
2. 图片区域最高只占 A4 页高约 24%；会根据上方填写内容自动再缩小。
3. 上方 DESCRIPTION、LOCATION、日期、PRESSURE TEST 数据全部完整显示。
4. 当填写太长时，照片会自动移至下一页，不遮盖内容或缩小成看不清的缩略图。
5. 多张照片会按 BEFORE/AFTER 成对排版，空间不足自动分页。
6. 保留 V1.2.1 的 iPhone 表单白底修复及所有原有功能。

升级现有测试网址：
1. 请先在 V1.2.1 的 PDF / Backup 中点击 Backup All Projects，并将备份存到 Files / iCloud。
2. 解压 ZIP，打开 Defect_List_V1_2_2 文件夹，将里面全部文件直接上传并覆盖 GitHub 测试仓库根目录的同名文件（不要额外套一层文件夹）。
3. 重新打开测试网址，确认页面显示 V1.2.2 TEST。旧版离线缓存可能要重新加载。
4. 不要卸载旧 App、清除 Safari 网站数据或改变测试网址，除非已经有完整备份。
5. 用 Photo Report 输入长 Description 并生成 PDF 测试排版。

此文件为独立测试版；尚未替你部署到 GitHub。
