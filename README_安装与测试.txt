DEFECT LIST V1.2.3 TEST — Defect List 手机界面优化

本次只更新 Defect List 手机界面：
1. 6 种状态筛选：All、Open、Pending、In Progress、Done、Not Set。
2. Lot、Block、Status 的卡片可读性增强；状态可直接调整。
3. Compact / Detailed 视图切换；默认保持详细描述。
4. 新增 Outstanding first 排序；切换 Project 时清除上一个 Project 的搜索条件。
5. Photo Report PDF 的图像大小、布局与分页算法与 V1.2.2 完全相同。
6. 保留所有 Project 数据与相片、A4 PDF、Backup/Restore。

安装方法：
1. 请先在当前 V1.2.2 的 PDF/Backup 页面选择 Backup，保存全部 Projects 数据。
2. 将 ZIP 内文件解压后上传到 GitHub 仓库根目录（包含 index.html、sw.js 等）。
   注意 index.html 必须在仓库最外层，不能把 ZIP 内文件夹整体当一层目录上传。
3. 上传成功后在 Safari 打开原 GitHub Pages 网站并刷新。顶部显示 V1.2.3 TEST。
4. 不要删除现有 iPhone App；同一 GitHub Pages 地址与同一浏览器存储区域会保留旧数据。
5. 如果仍显示旧版，可退出重进或刷新 Safari 页面。
6. 完成测试前请不要把它作为正式版。

实际设备端尚需确认：Project 切换、编辑、快速状态变更、PDF、数据保存。
